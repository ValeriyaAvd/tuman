## Запуск

Двойной щелчок по `START_GAME.cmd`. Требуются Python 3.10+ и pygame-ce.
Если зависимость не установлена: `python -m pip install -r requirements.txt`.

## Проверка

Из папки `tuman`:

```powershell
python tools/check_maps.py
python tools/check_visual_merge.py
python -m unittest discover -s tests -v
```

`check_visual_merge.py` сравнивает данные всех трёх карт и контрольные суммы
кода и защищённых изображений с исходной версией. При дальнейших намеренных
изменениях геймплея этот снимок следует обновить.

## Редактирование карты

В `street.tmj` исходные слои с непрозрачностью 0 сохраняют игровую геометрию.
Их tileset-файлы находятся в `tilesets/logic`. Слои `Art / ...` рисуют оформление,
а их tileset-файлы в `tilesets/visuals` не содержат коллизий и источников света.
Не скрывайте исходные слои через `visible=false`: для тайлов это отключает
обработку их игровых свойств. При перемещении интерактивного объекта в Tiled
нужно согласованно менять его изображение и исходную игровую зону.
