# Карты и локации в Tiled

## Открыть проект

В Tiled выбери File → Open File or Project и открой `data/maps/Tuman.tiled-project`.
Далее открой `street.tmj` или `shop.tmj`. Карты уже содержат настоящую графику.
Игра читает сохранённые `.tmj` и `.tsj` напрямую по [формату Tiled JSON](https://doc.mapeditor.org/en/stable/reference/json-map-format/).
Программа Tiled для запуска игры не требуется.

## Палитры графики

В каждой карте подключены четыре тайлсета:

| Тайлсет | Для чего |
| --- | --- |
| Terrain | Небольшая палитра: трава, асфальт, плитка, пол, лужи, разметка, люк, пропасть и стены |
| Objects | Целые дом, магазин, машина, стеллаж, холодильник, дерево, куст, фонари и забор |
| World | Точные тайлы исходных карт, включая все варианты текстур и части зданий |
| Decor | Исходные высокие объекты с сохранённой глубиной отрисовки |

Начинай строительство с **Terrain** и **Objects**. `World` нужен для точной правки перенесённых сцен:
зажми правую кнопку на карте и выдели нужный участок как кисть, например целое здание.

Покрытия рисуй на обычном Tile Layer. Для целого объекта выбери тайл в `Objects`,
переключись на Object Layer и используй Insert Tile. Его нижний левый угол — точка размещения.
Высокие объекты этого слоя сортируются вместе с героем по глубине.
Готовые объекты `Objects` имеют встроенные прямоугольные коллизии;
фонари, окна магазина/дома и холодильник также переносят свои источники света.
Можно рисовать высокие объекты и на тайловом слое: добавь слою bool-свойство `depth_sort = true`.

**Важно для перенесённых сцен:** исходные здания находятся в тайлах `World`, а их коллизии,
осмотры и свет — отдельными объектами. При перемещении/удалении такого здания обнови связанные зоны
в слоях `Collisions`, `Story` и `Lights`. У новых объектов из палитры `Objects` коллизии и свет
перемещаются вместе с изображением; сюжетные зоны всё равно задаются отдельно.

## Слои объектов

Названия слоёв служат для удобства; поведение задаёт поле **Class** объекта (старое название — Type).
Свойства добавляются в Custom Properties. Скопируй похожий объект из готовой карты и измени значения.
Слой с зонами можно скрыть в редакторе: его логика продолжит работать, а графика скрытого слоя не рисуется.

| Class | Форма | Свойства / назначение |
| --- | --- | --- |
| `collision` | Прямоугольник | Непроходимая зона |
| `light_blocker` | Прямоугольник | Перекрывает луч фонарика; для здания закрывай крышу, оставляя фасад ниже неё |
| `light_facade` | Прямоугольник | Видимая полоса фасада: принимает свет спереди, перекрывает его по бокам |
| `puddle` | Прямоугольник | Вода: отражения, круги и брызги от шагов |
| `spawn` | Точка | **Name** — имя точки; `entry` обязателен для каждой карты |
| `monster` | Точка | Место появления монстра; здоровье задаёт выбранная сложность |
| `door` | Прямоугольник | `target`: имя карты без `.tmj`; `spawn`: имя точки назначения; `facing`: up/down/left/right; `hint`: подсказка |
| `car` | Прямоугольник | Зона поиска фонарика; первая машина стартовой карты используется во вступлении |
| `item` | Прямоугольник | `item`: `pipe` или `note` |
| `light` | Точка | `kind`: lamp, lamp_broken, window, booth или fridge |
| `spot` | Прямоугольник | `kind`: произвольный идентификатор; `approach`: первая реплика; `inspect`: JSON-массив реплик |
| `remark` | Прямоугольник | `text`: автоматическая одноразовая реплика |

Все перечисленные свойства — **string**, кроме свойства карты `inside` (**bool**).
Координаты объектов — пиксели графики Tiled (при загрузке делятся на ART_SCALE = 2), клетка равна 32×32.
Точки `spawn` и `monster` обозначают позицию ног персонажа, а не центр картинки.
Расположи `entry` на свободном полу, не внутри коллизии.

Пример `inspect`: `["Дверь заперта.", "Изнутри слышен шорох."]`.
Последняя реплика повторяется. Пустой `approach` отключает автоматическую реплику при приближении.
Тексты осмотра и зон теперь хранятся в самих картах; старые таблицы в `texts.py` нужны мигратору.
Общие тексты вступления, предметов и записки пока остаются в `texts.py`.

Предмет `note` — одна записка на карту с общим текстом. Предмет `pipe` активирует существующую систему
оружия и появление монстров. Эти правила игры сохранены; разные квестовые предметы требуют отдельной логики.

## Создать новую локацию

1. File → New → New Map: **Orthogonal**, **Fixed size**, Tile size **32×32**.
2. Сохрани как `data/maps/cellar.tmj` (Tiled JSON map). Имя `cellar` станет ID локации.
3. Map → Add External Tileset: подключи `tilesets/terrain.tsj` и `tilesets/objects.tsj`.
4. Создай Tile Layer, нарисуй землю. Создай Object Layer, расставь объекты.
5. Добавь точку с Class `spawn`, Name `entry`. В свойствах карты добавь bool `inside`:
   true — темнота помещения, false — уличный туман.
6. На исходной карте добавь прямоугольник Class `door` с `target = cellar`, `spawn = entry`.
   На новой карте создай обратную дверь и точку прибытия на исходной карте.
7. Выполни `python tools/check_maps.py`, затем запусти игру.

Никаких записей в Python-реестре добавлять не нужно: игра обнаруживает все `data/maps/*.tmj`.
Стартовая локация выбирается полем `start` в `data/maps/locations.json`.
Если на стартовой карте нет `car`, вступление пропускается и герой появляется в `entry`.

Карты загружаются при первом посещении и остаются в памяти. Состояния монстров, записок и осмотров
сохраняются при возвращении. После смерти текущая логика игры сбрасывает монстров в уже загруженных
локациях, возвращает героя на стартовую карту и сохраняет собранные предметы.

## Свои тайлсеты

Поддерживаются JSON-тайлсеты `.tsj` с атласом или отдельными изображениями, относительные пути к PNG,
вложенные группы слоёв, прозрачность и отражения тайлов. Для объектов выбери Object Alignment **Bottom Left**.
Используй Tile Collision Editor для прямоугольных коллизий или bool-свойство тайла `solid = true`
для блокировки всей картинки. Свойство тайла `ground` (string: soft/hard/water) определяет звук шагов.
Для высокой графики `sort_y` (int) задаёт линию глубины относительно верхнего края изображения.
Свойство тайла `motion` (string) включает процедурную анимацию: `tree`, `bush`, `grass`, `reeds`,
`paper`, `cloth`, `fire`, `lamp`, `lamp_broken`.
Крона дерева движется, но его основание, линия глубины и коллизия остаются неподвижными.
Фонари мигают независимыми короткими сериями; яркость стекла, свечения и звук связаны.
Строка `roof_rect` задаёт локальную область крыши: JSON `[x, y, width, height]` в пикселях тайлсета.
Готовые дом и магазин из Objects уже имеют такую область, которая переносится вместе с объектом.
Для зданий из тайлов World используй прямоугольники `light_blocker` в слое Lighting occlusion:
оставь снизу полосу фасада примерно 28px для дома или 36px для магазина.
Тень строится от актуального положения фонарика в руке и закрывает также пространство за крышей.
`facade_rect` — JSON-прямоугольник полосы фасада в пикселях тайлсета: её боковые края останавливают
луч, направленный вдоль стены. Готовые здания Objects уже имеют это свойство.
Внутри помещений свет перекрывают стены и физические препятствия.
Необязательное string-свойство `lights` содержит JSON вида `[["lamp", 9, 5]]`:
тип и координаты источника света относительно верхнего левого угла изображения.
Для огня есть тип источника `flame`, с тёплым переменным свечением.

В палитре **Abandoned city** лежат новые баки, горящая бочка, растения, вода и декали.
Слои **Ground details**, **City props**, **Water**, **City logic** сохраняют оформление и интерактивные зоны.
Для движущихся декалей используй bool `ground_detail = true`, чтобы они оставались под персонажами.
Объектный слой с bool `ground = true` рисуется в базовую поверхность карты.
Лужа может быть зоной `puddle` с графикой на слое Water, либо тайлом со string `ground = water`:
нарисованная в Tiled вода автоматически получает реакцию на шаги.
Труба находится под парой мусорных баков; её точка меняется объектом item/pipe в Items.

Формат данных Tile Layer: **CSV** либо Base64 без сжатия / с zlib / gzip.
Бесконечные, изометрические карты, TMX/TSX, Zstandard, image layers, анимации тайлов,
нестандартное направление отрисовки и повёрнутые/полигональные коллизии не входят в поддерживаемый формат.
Внешние Object Templates сначала отсоедини через Detach Template.
Для изменения размера объекта меняй исходный PNG/тайлсет; растяжение и вращение tile objects не поддерживаются.

## Ресурсы и миграция

- `data/maps/*.tmj` — активные карты.
- `data/maps/tilesets/` — тайлсеты и графика; всё включается в PyInstaller-сборку через `data/`.
- `tools/legacy/*.txt` — архив исходных карт, игра его не читает.
- `tools/migrate_tiled.py` — архивный разовый конвертер. Для актуальной графики 32px запуск заблокирован.
  Миграция разрешения уже выполнена; описание и исходники — в `ART.md` и `art_source/`.
- `tools/check_maps.py` — проверяет загрузку всех карт, ресурсы, двери и свободные точки появления.
- `tests/test_tiled.py` — сравнение геометрии с сохранёнными картами до обновления графики и проверки загрузки/игрового цикла.
- `tests/test_world_life.py` — точки хвата, дыхание/покачивание, независимые фонари, тени и VHS.

Изменения подхватываются после сохранения карты и перезапуска игры; горячей перезагрузки нет.
